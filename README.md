# อัลบั้มภาพ Mild

เว็บไซต์อัลบั้มภาพแบบพลิกหน้าที่เปิดใช้งานได้ทันที ไม่ต้องติดตั้งแพ็กเกจหรือเริ่มเซิร์ฟเวอร์

## วิธีเปิดใช้งาน

เปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์ รูปทั้งหมดในโฟลเดอร์จะแสดงเป็นอัลบั้ม 2 หน้า พร้อมแกลเลอรีรูปในแต่ละหน้า

## วิธีเปลี่ยนรูป

1. คัดลอกรูปของคุณมาไว้ในโฟลเดอร์เดียวกับ `index.html`
2. เปิด `script.js` แล้วแก้รายการชื่อไฟล์ในตัวแปร `photos` ให้ตรงกับรูปของคุณ เช่น `"รูปวันหยุด.jpg"`
3. บันทึกไฟล์แล้วรีเฟรชหน้าเว็บ จำนวนหน้าและตัวเลือกนำทางจะปรับตามจำนวนรูปให้อัตโนมัติ

ระบบรองรับไฟล์รูปที่เบราว์เซอร์เปิดได้ เช่น JPG, PNG และ WebP กดที่รูปเพื่อดูขนาดใหญ่ ใช้ปุ่มลูกศรบนหน้าหรือปุ่มซ้าย/ขวาบนคีย์บอร์ดเพื่อเปลี่ยนคู่หน้า พร้อมแอนิเมชันพลิกกระดาษบนหน้าจอใหญ่และแอนิเมชันแบบกระชับบนมือถือ โดยเคารพการตั้งค่าลดภาพเคลื่อนไหวของอุปกรณ์
